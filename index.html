Les 3 étapes

1Charge un fichier .glb et télécharge sa page 3D.
2Publie cette page HTML sur ton hébergement HTTPS.
3Colle l'adresse publique ici, génère le code et colle-le dans Genially.

Important : le code iframe ne peut pas utiliser un fichier qui reste uniquement sur ton ordinateur. La page 3D doit être hébergée en ligne pour être visible par les autres.
